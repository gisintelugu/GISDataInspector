# GIS Data Inspector

Professional QGIS vector data statistics and QA/QC inspection plugin.

## V1.5
- All vector layers in the QGIS project
- QA/QC dashboard with PASS / WARNING / ERROR indicators
- Polygon, line and point inspection
- Geometry, attribute, quality and duplicate analysis
- Export report to HTML
- Export report to PDF
- Export structured QA/QC workbook to Excel (.xlsx)
- Automatic date/time filenames
